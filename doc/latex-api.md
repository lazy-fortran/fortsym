# LaTeX output

`fortsym_latex` writes a self-contained `.tex` artifact from the same
`expr_t` used for generated kernels. It is write-only. LaTeX is not accepted by
the expression parser, and the output contains bare math macros so the
consumer owns equation environments, labels, and numbering.

```fortran
use fortsym
use fortsym_latex

type(latex_t) :: tex
type(arena_t), target :: a
type(expr_t) :: b

call a%init()
b = sym(a, "Bfield")
call tex%source("field derivation")
call tex%name("Bfield", "B_{r}")
call tex%eq("Bfield", b)
call tex%write("generated/eqs.tex")
```

The file is deterministic:

```latex
% generated by fortsym -- do not edit
% derivation: field derivation
\newcommand{\eqBfield}{B_{r}}
```

Equation labels are mapped to letters-only control-sequence names. Digits and
punctuation and separators are spelled out, so labels
such as `gamma_1` cannot accidentally terminate a LaTeX control sequence.
Two labels that map to the same macro are refused with both labels named.

The printer follows the fixed conventions below. There is one override map,
`tex%name`, for project notation:

| Expression | Output |
| --- | --- |
| `x + y` | `x + y` |
| `x*y` | `x\,y` |
| `x/y` | `\frac{x}{y}` |
| `x**2` | `x^{2}` |
| `sqrt(x)` | `\sqrt{x}` |
| `log(x)` | `\ln{\left(x\right)}` |
| `sym("q0")` | `q_{0}` |
| `sym("weight_1_bar")` | `\bar{\mathrm{weight}_{1}}` |

Registered notation is treated as potentially scripted. For example,
registering `Bcon_r` as `\mathcal{B}^{r}` and squaring it emits
`\left(\mathcal{B}^{r}\right)^{2}` rather than an invalid ungrouped script.

An optional third argument to `tex%eq` is emitted as a companion macro named
`\assumption...`. This keeps a supplied domain condition beside its equation.
The writer never invents or drops one. A consumer that has no assumption emits
no companion macro.

The fixture test compares every output line with independently written
expected strings and then feeds the generated macros into a minimal `amsmath`
document. It also checks duplicate macro refusal and the explicit write-only
parser refusal.
